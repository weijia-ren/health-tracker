# Development plan

## Phase 1: local mobile beta

1. Start from the standalone files in this folder.
2. Review mobile layout on iPhone-sized width first.
3. Replace starter resources with reviewed, source-linked health resources.
4. Feedback link is connected; verify it again after deployment.
5. Simple app icons and install metadata are added; re-check after deployment.
6. Test export/import/delete data.
7. Publish to Netlify, Cloudflare Pages, or GitHub Pages.

## Phase 2: early user feedback

Share with 5-10 people first. Ask:

- Did you understand what to do immediately?
- Would you use this daily?
- Was the privacy explanation clear?
- What felt missing?
- Did you want cloud sync?
- Which resource topics were most useful?

## Phase 3: polish if people use it

- Better 7-day review screen
- More resource categories
- Optional reminder instructions
- Better accessibility pass
- Multilingual content if useful
- Optional cloud sync only if enough users ask

## Free distribution recommendation

Use a static host:

- Netlify: easiest polished beta and previews
- Cloudflare Pages: strong free hosting
- GitHub Pages: good for open-source distribution

Avoid a backend until there is clear user demand.
