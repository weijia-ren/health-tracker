# Mobile design notes

## Design principle

Mobile-first, thumb-friendly, low typing.

## Navigation

Use four bottom tabs:

1. Today
2. Trends
3. Resources
4. Settings

## Today screen

The Today screen should be the default landing screen. Users should be able to check in quickly without reading long explanations.

The four cards are collapsible:

- Sleep: length, bedtime, quality
- Nutrition: balance, supplement taken
- Exercise: cardio, strength, stretch
- Stress & recovery: meditation, social activity, short thanks/pray note

The top summary should make privacy visible and frame incomplete entries as partial progress, not failure.

## Touch targets

- Minimum input/button height: about 48px
- Large save button
- Native time picker
- Number inputs for minutes
- Button rows for ratings
- Toggles for yes/no habits

## Content separation

Tracking and learning should be separate:

- Today = quick check-in
- Resources = tips and source-linked content

Only show one short contextual tip per check-in card.
